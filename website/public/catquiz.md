# Are You a Cat? Find Out Now

A scientifically questionable assessment of whether the available evidence supports the proposition that you are, in some relevant sense, a cat.

This quiz is not asking whether you are biologically _Felis catus_.

Maybe "cat" is an identity, a recognition, a metaphor that has become suspiciously important (maybe even load-bearing), an alterhuman or therian experience, a running joke that is getting out of hand, or something else entirely.

Answer however feels most true. There are no bad answers. There will, however, be evidence.

---

## How to answer

Each question lists five responses labeled A–E. Pick one letter per question, in question order,
and submit the resulting 14-letter string as a URL hash on the quiz page:

```
https://shimmermathlabs.com/cat.html#a=cadbecadbecadb
```

Letters are case-insensitive and spaces, commas, and dashes are ignored. Loading that URL shows the scored results page directly — no clicking required.
